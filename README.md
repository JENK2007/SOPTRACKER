# SOP Tracker (Web Application)

This is a modern, AI-powered web application designed to help you efficiently track and manage your tasks and Standard Operating Procedures (SOPs). It provides a simple and intuitive user interface running in your browser.

This repository contains everything you need to run your app locally.

## Run Locally

**Prerequisites:**  Node.js


1. Install dependencies:
   `npm install`
2. Run the app:
   `npm run dev`
